# Политика конфиденциальности — «Три плитки» (Tiles)

Дата последнего обновления: 30.10.2026

Настоящая политика описывает, как мобильное приложение «Три плитки»
(идентификатор пакета `com.profn.tiles`, далее — «Приложение») обрабатывает
данные пользователей.

## 1. Какие данные собираются

Приложение не собирает, не хранит и не передаёт персональные данные:
нет регистрации, аккаунтов, аналитики и трекинга. Игровой прогресс
(пройденный уровень) и настройка звука сохраняются только локально
на устройстве и не покидают его. Для показа рекламы приложение
обращается к рекламному сервису, который может обрабатывать
технические идентификаторы устройства (см. раздел «Реклама»).

## 2. Разрешения

- `INTERNET` — загрузка рекламы.
- `ACCESS_NETWORK_STATE` — проверка доступности сети перед запросом рекламы.
- `VIBRATE` — тактильный отклик при действиях в игре.

## 3. Реклама

В приложении показывается реклама через Рекламную сеть VK (myTarget).
Настройки приватности рекламного SDK сконфигурированы так, что реклама
передаётся только неперсонализированная: включён флаг возрастных
ограничений и отозвано согласие на персонализацию. Рекламный сервис
может обрабатывать технические идентификаторы устройства в объёме,
описанном его собственной политикой конфиденциальности
(https://ads.vk.com/highload/privacy_vkrn). Часть рекламы — видео
с вознаграждением: за полный просмотр игрок может получить игровое
преимущество (продолжение партии). Просмотр рекламы добровольный.

## 4. Дети

Приложение доступно пользователям любого возраста. Реклама передаётся
только неперсонализированная с включёнными возрастными ограничениями,
персональные данные пользователей, включая детей, не собираются.

## 5. Удаление данных

Все данные приложения хранятся локально и удаляются вместе с удалением
приложения с устройства. По вопросам обработки данных рекламным сервисом
обращайтесь к политике Рекламной сети VK по ссылке выше.

## 6. Изменения политики

Актуальная версия политики всегда доступна по данному адресу.
Существенные изменения будут отражены в дате обновления выше.
